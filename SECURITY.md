# Security Policy

## Supported Versions

Security updates are applied continuously to the latest release deployed across the sovereign fleet.

| Version | Supported          |
| ------- | ------------------ |
| main    | Yes                |
| < main  | No                 |

## Reporting a Vulnerability

If you discover a security vulnerability within Shenron or dragonballfr.com, please report it responsibly:

1. **Do not create a public issue**.
2. Submit reports directly via GitHub Private Vulnerability Reporting or contact security administrators directly.
3. Include detailed steps to reproduce the vulnerability, along with sample requests, affected routes, or payloads where applicable.

## Disclosure Policy

- Vulnerability reports are acknowledged within 24 hours.
- Fixes are tested across isolated staging environments prior to production activation.
- Coordinated public disclosure follows remediation and production verification.
