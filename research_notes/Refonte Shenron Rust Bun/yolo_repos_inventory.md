# Inventory of the `yolo` repository family (C:\src) for a unified `yolo-stack` monorepo

Research date: 2026-11-04. All sources are local files; "Source" links are absolute local paths. No repository was modified. Compile evidence comes from `cargo check --offline` runs executed read-only in the existing checkouts.

## Key Question 0: Per-repository inventory (purpose, git, layout, workspaces, tooling, licenses)

### Takeaway

Seventeen directories were inventoried. Only three are substantial code bases with long histories (`yolo-ui` 7,268 commits on a Dioxus-fork history, `bun-ui` 409 commits, `yolo-cross` 2,026 commits on a `cross-rs/cross` mirror); the remaining `yolo-*` repos are 1 to 11 commits old (all created 2026-11-04) and mostly contain docs, Bun scripts and freshly moved crates. `yolo-rs` and `yolo-cf-src` are not Git checkouts; `awesome-rust-yolo-rs-sync` is a bare-ish clone with only `.git/`.
