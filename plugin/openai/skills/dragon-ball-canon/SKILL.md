# Canon checks

Use `dragonball.canon_check` for the verdict and `dragonball.canon_references` for its evidence. State which continuity the question concerns. Distinguish the original manga, supervised manga and films, anime-only material, games, and promotional works.

Report the verdict and its basis together. Link the returned references. If the source is missing, the continuity is ambiguous, or the live result conflicts with a cited primary source, describe that limit instead of choosing a side without evidence. The manga and Akira Toriyama's published statements take priority; do not use Fandom as authority.

This workflow is read-only. Do not create or edit editorial records.
