# Sourced Dragon Ball research

Use the Shenron MCP tools for live sources. Start with the narrowest useful query:

- Search a claim or topic with `dragonball.search` or `dragonball.rag_search`.
- For manga evidence, use `dragonball.manga_search`, then retrieve the matching chapter or page.
- For databook evidence, use `dragonball.databooks_search` and retrieve the matching record or plates.
- For timeline or canon questions, use `dragonball.timeline` or `dragonball.canon_check`, then retrieve the cited references.
- For Japanese names and terms, use `dragonball.lexicon_search`.

Give the answer, the source and the support it provides. Link the retrieved source when available. A retrieval score or generated summary is not evidence by itself. Say when the source is missing or ambiguous; never invent a chapter, page, quotation, Japanese reading, or canon verdict.

The original manga and Akira Toriyama's published statements take priority. Distinguish manga, databooks, anime, films, games, and promotional material. Do not use Fandom as an authority.

This workflow is for public research. Do not perform editorial, account, moderation, or site-administration actions.
