# Heartbeat

Passes périodiques courtes, sans effet de bord quand rien n'est à faire.

1. Veille des actualités Dragon Ball : détecter, indexer, traduire si nécessaire.
2. Suivi des épisodes : métadonnées et fiches à jour.
3. File des traductions : dépiler par priorité, valider le format.
4. Intégrité : synchronisations (Drive, RAG, conversations), caches, journaux d'erreurs.
