# shenron-cli

Commande `shenron`: santé, RAG, entraînement, pont OCR des databooks, API databooks de dragonballfr.com, manga, configuration.

## Commandes

Sur vps ou bunos, jamais sur le poste Windows.

```sh
cargo check -p shenron-cli
cargo nextest run -p shenron-cli
```

Lint du workspace: `cargo lint`. Règles générales: `AGENTS.md` à la racine.
