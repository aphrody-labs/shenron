# shenron-studio

Commandes Tauri de Shenron Studio: santé, RAG, entraînement, corpus et modèles locaux, chat public.

## Commandes

Sur vps ou bunos, jamais sur le poste Windows.

```sh
cargo check -p shenron-studio
cargo nextest run -p shenron-studio
```

Lint du workspace: `cargo lint`. Règles générales: `AGENTS.md` à la racine.
