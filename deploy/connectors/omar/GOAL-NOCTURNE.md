## 7. STRATÉGIE D'AUTO-RÉSOLUTION EN CAS D'ANOMALIE

- **Port local déjà occupé** : Identifier le processus avec `netstat -ano | findstr :<port>` et libérer le port ou exécuter `just tunnel-down` puis `just tunnel-up`.
- **Mémoire VRAM GPU saturée** : Réduire `--batch-size 2` ou activer le CPU fallback automatique (`--device cpu`).
- **Base de données inaccessible** : Le système se replie automatiquement sur le VFS SQLite embarqué (`shenron-vfs.public.sqlite`).
- **Dérive détectée sur OpenAPI ou AGY** :
  - Pour OpenAPI : `bun packages/api/scripts/openapi.ts`
  - Pour AGY : `bun scripts/plugin/agy-manifest.ts`
