# Shenron administration

Before an administrative operation, read the canonical contract in [plugin/skills/shenron-admin/SKILL.md](../../../plugin/skills/shenron-admin/SKILL.md) and its linked references. Keep that file as the single source of the request schema and verification steps. Check `AGENTS.md`, `GOAL.md`, the current catalogue, authorization, and applicable freezes. A catalogue audit or setup request alone does not authorize editorial writes; never bypass missing credentials, owner controls, or the databook freeze.
