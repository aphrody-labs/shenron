# Inventaire de l’administration — 2026-11-05

Inventaire de l’espace `/admin` et des routes `/api/admin` restants après la purge de la branche
`claude-admin-purge` (base `origin/main` 2e465772). Il sert à planifier la refonte progressive.

## Méthode

- Pages et routes : `apps/site/src/app/admin/**/page.tsx` (81, plus le relais `dbxv2/media`) et
  `apps/site/src/app/api/admin/**/route.ts` (20). Rôle : description `admin.pages.<id>` de
  `messages/fr.json` quand la page est au registre `components/admin/admin-pages.ts`, sinon lecture du code.
- Sources de données : appels du client admin (`api.*` de `lib/admin-api.ts`, relayés par
  `/api/bot-admin/*` vers l’API REST du bot), chaînes `/api/...` du site et modules de `lib/` qui touchent
  une base ou un service (fermeture des imports locaux de la page).
- Écritures : verbes HTTP non GET émis par la page (`bot` = via le proxy bot), « actions serveur » pour
  les modules `"use server"`. Pour les routes : méthodes exportées.
- Trafic : `docker logs --since 72h shenron-gateway` sur prod, lecture seule, le 2026-11-05. Les accès
  aux pages viennent de navigateurs (Chrome 157 surtout ; un Googlebot reçoit la redirection de garde).
  Entre parenthèses : appels `/api/bot-admin/*` exacts des sources bot de la page. La passerelle voit
  aussi les appels directs à l’API du bot (client `Bun/1.4.5`) ; les appels serveur à serveur du site
  vers le bot ne passent pas par elle.
- Cibles : **Rust Dioxus** (écran natif client de l’API existante), **Bun service** (handler à déplacer
  dans `@aphrody/shenron-api` derrière `Bun.serve`), **supprimer plus tard** (doublon ou redirection,
  après accord du propriétaire).

Hors périmètre, déjà en portage Rust par un autre agent : `/admin/ai`, `/admin/canon`, `/api/admin/ai`,
`UnifiedIaCockpit`, `NativeAiPanel`, `ia-cockpit-view`, `lib/ia-cockpit*`, `lib/canon-engine`.

Les anciens segments français (`/admin/ia`, `/admin/chronologie`, `/admin/ursaf`, `/api/admin/entites`…)
restent servis par les 308 de `STAFF_ROUTE_RENAMES` (`packages/config/src/legacy-routes.ts`) et ne
figurent pas ci-dessous.
