# Documentation

- `decisions/`: décisions d'architecture (ADR), format de `yolo-stack`.
- `architecture/README.md`: couches, runtimes et frontières.
- `operations/`: production, déploiement, sauvegarde et reprise.
- `runbooks/content.md`: chaînes de contenu (OCR, traduction, wiki, news, RAG, CDN).
- `plans/refonte-rust-bun-yolo-stack.md`: plan de la refonte.
- `licenses/koharu/`: licences du code Koharu intégré.
- `reference/root/PLAN.md`: doctrine éditoriale en JSON, lue par `packages/pipeline`. Ne pas déplacer sans changer le code qui la lit.

Tout fait daté ou chiffré dans ces pages vient du code, de la configuration ou d'un relevé daté. Un fait qu'on ne peut pas vérifier n'a pas sa place ici.
