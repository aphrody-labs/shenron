# @aphrody/shenron-activity

Règles et protocole de l'Activité Arène Shenron: protocole réseau, salons par instance, règles du Quiz Budokai, récompenses zeni bornées, reçus de règlement signés.

## Commandes

```sh
bun run --filter @aphrody/shenron-activity test
bun run --filter @aphrody/shenron-activity lint
bun run --filter @aphrody/shenron-activity typecheck
```

Les tests utilisent `bun test`. Lancer `test` avant tout commit qui touche ce dossier.

Règles générales: `AGENTS.md` à la racine.
