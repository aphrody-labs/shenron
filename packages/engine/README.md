# @shenron/engine

Moteur de jeu: backend GPU, pipeline WebGPU/WASM, canvas vectoriel, noyau de combat déterministe.

## Commandes

```sh
bun run --filter @shenron/engine test
bun run --filter @shenron/engine lint
bun run --filter @shenron/engine typecheck
```

Les tests utilisent `bun test`. Lancer `test` avant tout commit qui touche ce dossier.

Règles générales: `AGENTS.md` à la racine.
