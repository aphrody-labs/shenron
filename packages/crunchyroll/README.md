# @aphrody/shenron-crunchyroll

CLI Crunchyroll sans navigateur, serveur MCP et fournisseur de service pour Shenron (métadonnées seulement).

## Commandes

```sh
bun run --filter @aphrody/shenron-crunchyroll build
bun run --filter @aphrody/shenron-crunchyroll test
bun run --filter @aphrody/shenron-crunchyroll lint
bun run --filter @aphrody/shenron-crunchyroll typecheck
```

Les tests utilisent `bun test`. Lancer `test` avant tout commit qui touche ce dossier.

Règles générales: `AGENTS.md` à la racine.
